# 📁 dnh-project/

**Назначение:** Приложение «Do No Harm» — калькулятор дозировки + руководство по игре.

---

## Описание

Приложение для внутриигрового калькулятора дозировки препаратов.

### Стек
- React 19
- Vite
- TypeScript
- Electron (desktop)

### Запуск
```bash
cd dnh-project
npm install
npm run dev
```

---

## Связанные проекты
- `dnh-calculator/` — отдельный калькулятор
- `Do No Harm: Руководство/` — извлечённые данные из игры
