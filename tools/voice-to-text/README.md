# 🎙 Голосовой ввод для Claude

Python-утилита, которая висит в фоне и слушает глобальную горячую клавишу **Ctrl+'**.

Работает в **toggle-режиме**: первое нажатие — начать запись, второе — остановить.

## ⚡ Установка и запуск

### 1️⃣ Установи зависимости (один раз)

Открой PowerShell **от имени администратора** и выполни:

```powershell
cd C:\Ren\tools\voice-to-text
py -3.12 -m pip install -r requirements.txt
```

### 2️⃣ Запуск скрипта

**Вариант А — С окном (для теста):**

```powershell
py -3.12 main.py
```

**Вариант Б — Тихий (без окна, двойной клик):**

Дважды кликни **`silent_start.vbs`** — скрипт запустится в фоне.

**Вариант В — Автозагрузка (запускается с Windows):**

Дважды кликни **`toggle_autostart.bat`**.

## 🎤 Как пользоваться

1. **Кликни** в поле ввода чата с Claude
2. Нажми **Ctrl+'** — начнётся запись (услышишь звук)
3. Говори сколько нужно
4. Нажми **Ctrl+' ещё раз** — запись остановится, текст распознается и вставится
5. Нажми **Enter** сама, когда будешь готова отправить
6. Повторяй

Для остановки: найди окно терминала и закрой его, или убей процесс python.exe.

## 📁 Файлы

| Файл | Описание |
|---|---|
| `main.py` | Запуск с окном терминала (для отладки) |
| `main_background.py` | **Фоновый скрипт** — без окна, пишет логи в файл |
| `main_clipboard.py` | Только копирует в буфер (вставляй Ctrl+V сама) |
| `test_hotkey.py` | Тест — проверяет, ловится ли Ctrl+' |
| `silent_start.vbs` | Тихий запуск `main_background.py` без окна |
| `start_voice.bat` | Запуск через bat (с минимальным окном) |
| `toggle_autostart.bat` | Добавляет/убирает автозагрузку |
| `voice_input.ps1` | PowerShell-вариант без Python |

## 🛠 Устранение неполадок

| Проблема | Решение |
|---|---|
| `ModuleNotFoundError: No module named 'pyaudio'` | `py -3.12 -m pip install pipwin && py -3.12 -m pipwin install pyaudio` |
| No microphone detected | Проверь, что микрофон подключён и разрешён в настройках Windows |
| Распознаёт неправильно | Говори громче, ближе к микрофону, убедись что нет шума |
| `Network error` | Нужно интернет-соединение (Google Speech API) |
| Ctrl+' не работает | Запусти скрипт **от имени администратора** |
| Текст не вставляется | Убедись, что кликнула в поле ввода ЧАТА перед нажатием Ctrl+' |

## 📦 Зависимости

- **SpeechRecognition** — распознавание речи через Google API
- **pyaudio** — запись аудио с микрофона
- **pyperclip** — копирование в буфер обмена
- **keyboard** — глобальные горячие клавиши и эмуляция ввода

## 🔧 Альтернатива без Python

Если Python не хочет устанавливаться — используй встроенное распознавание Windows:

1. Нажми **Win + H** — откроется голосовой ввод Windows
2. Говори в любое текстовое поле
