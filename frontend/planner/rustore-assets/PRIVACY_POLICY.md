# Политика конфиденциальности

**Действует с:** 14 июля 2026 г.

## 1. Общие положения

Настоящая Политика конфиденциальности описывает порядок сбора, использования и хранения персональных данных пользователей мобильного приложения **«Планер»** (далее — «Приложение»).

## 2. Какие данные собираются

Приложение может собирать следующие данные:
- **Учетные данные** — логин и пароль для доступа к облачной синхронизации.
- **Данные календаря** — события, задачи, встречи и платежи, созданные пользователем.
- **Техническая информация** — версия ОС, модель устройства (только для диагностики ошибок).

## 3. Как используются данные

- События и задачи хранятся **локально** на устройстве пользователя.
- При включении синхронизации данные передаются на выбранный пользователем сервер.
- Мы **не передаем** данные третьим лицам.
- Мы **не используем** данные для таргетированной рекламы.

## 4. Хранение данных

- Локальные данные хранятся в зашифрованном хранилище приложения.
- Облачные данные хранятся на сервере, указанном пользователем в настройках.

## 5. Права пользователя

Пользователь вправе:
- Удалить все данные через меню «Настройки».
- Отключить синхронизацию в любой момент.
- Экспортировать данные в стандартном формате (при наличии функции).

## 6. Контакты

По вопросам, связанным с обработкой данных, обращайтесь:
- **Email:** planner-support@github.com

## 7. Изменения политики

Мы оставляем за собой право вносить изменения в настоящую Политику. Актуальная версия всегда доступна в репозитории проекта.
