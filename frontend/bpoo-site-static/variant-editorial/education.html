Образование

Программы профессионального обучения, повышения квалификации и переподготовки для востребованных профессий.

Программы

Направления обучения

Профессиональное обучение

Краткосрочные программы по востребованным рабочим профессиям. Обучение ведётся с учётом требований работодателей региона.

Повышение квалификации

Программы повышения квалификации для специалистов различных отраслей. Повысьте конкурентоспособность на рынке труда.

Профессиональная переподготовка

Переподготовка для получения новой специальности. Интенсивные программы с практикой и стажировками.

Дополнительное образование

Дополнительные образовательные программы для детей и взрослых: цифровые навыки, творчество, иностранные языки.
