# 📁 projects/

**Назначение:** Активные проекты в разработке.

---

## Содержимое

| Папка | Проект | Стек | Статус |
|-------|--------|------|--------|
| `backend/` | Planner Backend | Node.js, Express, Prisma, PostgreSQL | 🔥 Активный |
| `frontend/` | Planner + BPOO Frontend | React 19, Vite, Tailwind CSS | 🔥 Активный |
| `database/` | Planner DB | PostgreSQL, Prisma schema | 🔥 Активный |
| `dnh-project/` | Do No Harm App | React + Vite + Electron | 🎮 Активный |
| `dnh-calculator/` | DNH Калькулятор | React + Vite | 🎮 Активный |
| `Do No Harm: Руководство/` | DNH Руководство | AssetRipper, extracted data | 🎮 Активный |
| `olimpium/` | Olimpium Automation | Python, Playwright | 🤖 Авто |

---

## Быстрый старт

```bash
# Planner (fullstack)
cd backend/planner && npm run dev      # backend :5000
cd frontend/planner && npm run dev    # frontend :5173

# BPOO Site
cd frontend/bpoo-site && npm run dev

# DNH
cd dnh-project && npm run dev

# Olimpium
cd olimpium && python scripts/full_course_scraper.py
```
