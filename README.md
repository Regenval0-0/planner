# Планер — события, задачи, встречи и платежи

Приложение для Android (RuStore) и Windows с общим аккаунтом и синхронизацией через сервер.

- `backend/planner` — сервер (Node.js, Express, Prisma, PostgreSQL / SQLite для разработки)
- `frontend/planner` — приложение (React + Vite; Android — Capacitor, Windows — Electron)
- `deploy/` — запуск сервера на своём VPS (Docker + HTTPS)
- `render.yaml` — запуск сервера на Render

**Как запустить сервер, собрать приложения и опубликовать в RuStore:** [ЗАПУСК-И-RUSTORE.md](ЗАПУСК-И-RUSTORE.md)
