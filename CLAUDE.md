# Fullstack Learning Project: Node.js, React, DB

## 🎯 Goals
- Обучение пользователя Fullstack-разработке с нуля до уровня Junior+.
- Реализация проектов согласно Roadmap 2026.
- Постепенное внедрение TypeScript, Docker и AI-интеграций.

## 🛠 Tech Stack
- **Frontend:** React 19+, Next.js (App Router), Tailwind CSS.
- **Backend:** Node.js, Express $\rightarrow$ NestJS.
- **Database:** PostgreSQL (Relational), MongoDB (NoSQL).
- **Tooling:** Vite, Prisma/Drizzle ORM, Zod.
- **DevOps:** Docker, GitHub Actions.

## 📖 Execution Guidelines (Правила работы)
1. **Приоритет исполнения:** Выполнять задачи ровно так, как просит пользователь.
2. **Минимум теории:** Не давать поучений или советов, если об этом не просили.
3. **Объяснения по запросу:** Подробно объяснять код только тогда, когда пользователь задает вопрос «как это работает?» или «почему так?».
4. **TypeScript по умолчанию:** Использовать TS в проектах, так как это стандарт, но без лишних лекций о его пользе.

## 📂 Project Structure
- `/frontend` - React/Next.js приложение.
- `/backend` - Node.js сервер.
- `/database` - Скрипты миграций, схемы и Docker-конфиги БД.
- `/docs` - Материалы по обучению, заметки и архитектурные схемы.
