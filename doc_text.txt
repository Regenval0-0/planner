Обзорный доклад по React.js
Формат: Презентация c устной защитой
Цель: продемонстрировать понимание всех пройденных тем, умение выстраивать связи между ними и применять на практике.
В ходе выполнения работы необходимо осветить все перечисленные ниже темы:
Назначение React, проблема, которую он решает. Понятие виртуального DOM — объяснение на аналогиях. Сравнение императивного и декларативного подходов.
Структура проекта (CRA / Vite). Точка входа, процесс сборки, разница между dev и production. Назначение div#root.
Связь JSX и React.createElement. Правила написания (корневой элемент, camelCase, закрытие тегов). Проблема возврата нескольких элементов без фрагмента.
Функциональные vs классовые компоненты. Принцип единственной ответственности. Декомпозиция. Ошибка: объявление компонента внутри другого компонента.
Однонаправленный поток данных. Передача пропсов, деструктуризация, значения по умолчанию.
Назначение хука useState. Отличие состояния от пропсов. Асинхронность setState. Разница между передачей значения и функции-обновителя. Ошибка: прямая мутация стейта.
Назначение хука useState. Массив зависимостей и его варианты. Функция очистки (cleanup). Ошибка: бесконечный цикл ререндеров
Назначение роутинга в SPA. BrowserRouter, Routes, Route. Link vs a href. Динамические параметры. Ошибка: использование <a> вместо <Link>
Запросы к API. Где выполнять запросы. Обработка состояний loading / data / error.
