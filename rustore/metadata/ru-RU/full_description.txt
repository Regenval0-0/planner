# Планер — ваш персональный планировщик

**Планер** — это удобное приложение для планирования событий, задач, встреч и отслеживания платежей.

## Основные возможности

📅 **Календарь**
- Месячный просмотр с быстрым переключением между месяцами и годами
- Выбор даты в один клик

✅ **Задачи**
- Создавайте задачи с дедлайнами
- Отслеживайте сроки

📍 **Встречи**
- Планируйте встречи с точным временем начала и окончания
- Удобный просмотр по неделям

💰 **Платежи**
- Следите за регулярными платежами
- Указывайте суммы и настраивайте повторения

🔄 **Синхронизация**
- Работайте offline — все данные сохраняются на устройстве
- Подключите облачный сервер для синхронизации между ПК, Android и веб
- Real-time обновления через WebSocket

🔒 **Безопасность**
- JWT-аутентификация
- Восстановление пароля по секретному вопросу и номеру телефона
- Данные хранятся на вашем сервере или локально

🌐 **Мультиплатформенность**
- Android (RuStore, APK)
- Windows (Electron)
- Веб-браузер (PWA)

## Для кого это приложение

Идеально подходит для:
- Студентов и школьников — планирование учёбы и дедлайнов
- Фрилансеров — учёт встреч и платежей
- Людей, ведущих семейный бюджет — отслеживание регулярных расходов
- Всех, кто любит порядок в делах

## Технологии

React 19, Vite, Tailwind CSS, Node.js, Express, Prisma, PostgreSQL, Capacitor, Electron
