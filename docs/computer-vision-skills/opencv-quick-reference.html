🎥 OpenCV + Computer Vision Quick Reference

Шпаргалка по распознаванию видео для Fullstack-разработчика

1. Установка OpenCV + Python

# Установка OpenCV pip install opencv-python # Дополнительно: numpy, matplotlib pip install numpy matplotlib

2. Чтение видео

import cv2 # Открыть видеофайл cap = cv2.VideoCapture('video.mp4') # Или веб-камера (0 = первая камера) cap = cv2.VideoCapture(0) while cap.isOpened(): ret, frame = cap.read() if not ret: break cv2.imshow('Video', frame) if cv2.waitKey(1) == ord('q'): break cap.release() cv2.destroyAllWindows()

3. Детекция лиц (Haar Cascade)

face_cascade = cv2.CascadeClassifier( cv2.data.haarcascades + 'haarcascade_frontalface_default.xml' ) gray = cv2.cvtColor(frame, cv2.COLOR_BGR2GRAY) faces = face_cascade.detectMultiScale(gray, 1.3, 5) for (x, y, w, h) in faces: cv2.rectangle(frame, (x, y), (x+w, y+h), (255, 0, 0), 2)

4. Извлечение кадров из видео

cap = cv2.VideoCapture('video.mp4') fps = cap.get(cv2.CAP_PROP_FPS) frame_count = cap.get(cv2.CAP_PROP_FRAME_COUNT) count = 0 while cap.isOpened(): ret, frame = cap.read() if not ret: break # Сохраняем каждый 30-й кадр if count % 30 == 0: cv2.imwrite(f'frame_{count}.jpg', frame) count += 1

5. Whisper — распознавание речи из видео

# Установка pip install openai-whisper # Python код import whisper model = whisper.load_model("base") result = model.transcribe("video.mp4") print(result["text"])

6. ffmpeg — обработка видео (CLI)

# Извлечь аудио из видео ffmpeg -i video.mp4 -vn audio.mp3 # Обрезать видео (с 10 сек по 30 сек) ffmpeg -i video.mp4 -ss 10 -t 20 clip.mp4 # Извлечь кадр на 5 секунде ffmpeg -i video.mp4 -ss 00:00:05 -vframes 1 frame.jpg # Конвертировать в другой формат ffmpeg -i video.avi output.mp4
💡 Совет: Для real-time детекции используй MediaPipe — он легче OpenCV и работает быстрее на CPU.
