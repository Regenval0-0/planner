## 🎯 План обучения (4 недели)

### Неделя 1 — OpenCV основы
- Пройти курс Obrazum (модули 1-6)
- Установить OpenCV + Python
- Загрузить видео, извлечь кадры, применить фильтры

### Неделя 2 — Детекция + Трекинг
- Каскадные классификаторы Хаара (лица)
- MediaPipe (руки, поза)
- Трекинг объектов в видеопотоке

### Неделя 3 — YOLO + Нейросети
- Детекция объектов через YOLOv8
- Распознавание автомобильных номеров (практика itProger)
- Работа с видео в реальном времени

### Неделя 4 — Whisper + Проект
- Распознавание речи из видео
- Объединение CV + NLP: видео → текст + анализ
- Создать проект: "Распознавание лиц + транскрибация лекции"
