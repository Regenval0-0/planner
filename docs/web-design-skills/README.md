## 🎯 План обучения (4 недели)

### Неделя 1 — HTML + семантика
- Пройти вводный модуль Хекслета
- Выучить 20 основных тегов (шпаргалка WebsiteSetup)
- Сверстать простую страницу БПОО без CSS

### Неделя 2 — CSS основы
- Селекторы, box-model, типографика
- Практиковаться на CodePen
- Сверстать карточку и кнопку

### Неделя 3 — Flexbox + Grid + адаптив
- Гайды CSS-Tricks (Flexbox + Grid)
- Media queries
- Сделать адаптивную версию страницы БПОО

### Неделя 4 — Дизайн в Figma + проект
- Основы Figma (курс Нетологии)
- Создать макет лендинга
- Сверстать по своему макету
