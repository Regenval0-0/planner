2. CSS Box Model

.box { width: 300px; padding: 20px; border: 2px solid #000; margin: 10px; box-sizing: border-box; /* Включает padding и border в width */ }

3. Flexbox — выравнивание

7. Типографика

body { font-family: 'Inter', system-ui, sans-serif; font-size: 16px; line-height: 1.6; color: #212529; }
Совет: Используй clamp() для адаптивных заголовков — не нужно писать кучу media queries для текста.

8. Доступность (Accessibility)

  • Всегда добавляй alt к изображениям
  • Используй aria-label для иконок-кнопок
  • Цветовой контраст минимум 4.5:1
  • Фокус-стили для keyboard-навигации
  • Skip-link для быстрого перехода к контенту
