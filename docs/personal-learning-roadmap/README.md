# 🎯 Персональный Roadmap — Fullstack + AI

Создан для обучения с нуля до уровня Junior+ / Middle.

---

## 📊 Общая структура (12 месяцев)

### Этап 1: Фундамент (Месяцы 1-3)

| Навык | Зачем | Курс / Ресурс | Время |
|-------|-------|---------------|-------|
| **HTML5 + CSS3** | Скелет и внешний вид сайтов | [Хекслет — HTML/CSS](https://ru.hexlet.io/programs/html-css-basics-free) | 2-3 недели |
| **JavaScript база** | Интерактивность на странице | [learn.javascript.ru](https://learn.javascript.ru) | 3-4 недели |
| **Git + GitHub** | Контроль версий, командная работа | [GitHub Skills](https://skills.github.com/) | 1 неделя |
| **Figma (основы)** | Дизайн макетов, работа с UI | [Нетология — UX/UI](https://netology.ru/programs/web-ux-ui-design-free) | 1 неделя |

**Практика:** Сверстать 3 лендинга (БПОО + 2 своих), разместить на GitHub Pages.

---

### Этап 2: Frontend (Месяцы 4-6)

| Навык | Зачем | Курс / Ресурс | Время |
|-------|-------|---------------|-------|
| **React 18+** | Современный UI-фреймворк | [React Docs](https://react.dev/learn) | 3-4 недели |
| **TypeScript** | Типизация, меньше багов | [TypeScript Handbook](https://www.typescriptlang.org/docs/) | 2 недели |
| **Tailwind CSS** | Быстрая стилизация | [Tailwind Docs](https://tailwindcss.com/docs) | 1 неделя |
| **Vite** | Сборка проекта | [Vite Guide](https://vitejs.dev/guide/) | 3 дня |
| **React Router + Hooks** | Навигация, состояние | [React Router](https://reactrouter.com) | 1 неделя |

**Практика:** Сделать SPA-приложение (планировщик задач или дашборд), подключить API.

---

### Этап 3: Backend (Месяцы 7-9)

| Навык | Зачем | Курс / Ресурс | Время |
|-------|-------|---------------|-------|
| **Node.js + Express** | Серверная часть на JS | [Node.js Docs](https://nodejs.org/en/docs/) | 2-3 недели |
| **PostgreSQL** | Реляционная БД | [SQLBolt](https://sqlbolt.com) + [PostgreSQL Tutorial](https://www.postgresqltutorial.com/) | 2 недели |
| **Prisma ORM** | Работа с БД из кода | [Prisma Docs](https://www.prisma.io/docs) | 1 неделя |
| **JWT + Auth** | Аутентификация пользователей | [JWT.io](https://jwt.io/introduction) | 1 неделя |
| **REST API design** | Проектирование API | [REST API Tutorial](https://restfulapi.net/) | 3 дня |
| **Docker (основы)** | Контейнеризация | [Docker Getting Started](https://docs.docker.com/get-started/) | 1 неделя |

**Практика:** REST API для планировщика (CRUD + auth + БД), завернуть в Docker.

---

### Этап 4: AI / Computer Vision (Месяцы 10-11)

| Навык | Зачем | Курс / Ресурс | Время |
|-------|-------|---------------|-------|
| **Python (основы)** | Язык для AI/ML | [Python.org Tutorial](https://docs.python.org/3/tutorial/) | 2 недели |
| **OpenCV** | Обработка видео/изображений | [Obrazum — OpenCV](https://obrazum.com/course/компьютерное-зрение-на-opencv) | 2-3 недели |
| **Whisper** | Распознавание речи из видео | [OpenAI Whisper](https://github.com/openai/whisper) | 1 неделя |
| **MediaPipe / YOLO** | Real-time детекция | [Stepik — CV](https://stepik.org/course/109816/promo) | 1-2 недели |
| **FastAPI** | Python-backend для AI-сервисов | [FastAPI Docs](https://fastapi.tiangolo.com/) | 1 неделя |

**Практика:** Сервис «Видео → текст + детекция объектов» (Whisper + OpenCV + FastAPI).

---

### Этап 5: DevOps + Портфолио (Месяц 12)

| Навык | Зачем | Ресурс | Время |
|-------|-------|--------|-------|
| **GitHub Actions** | CI/CD, автоматизация | [GitHub Actions Docs](https://docs.github.com/en/actions) | 1 неделя |
| **Deploy (Vercel / Railway)** | Публикация проектов | [Vercel Docs](https://vercel.com/docs) | 3 дня |
| **Портфолио** | 3-4 проекта на GitHub | Собственные проекты | 2-3 недели |
| **Резюме + LinkedIn** | Поиск работы | — | 3 дня |
