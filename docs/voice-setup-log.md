# Сессия: Настройка голосового ввода — 2026-06-02

## Что сделано

### Python
- Установлен **Python 3.12** через winget (ранее стоял 3.14, с ним не ставился PyAudio)
- Установлены зависимости: `SpeechRecognition`, `PyAudio`, `pyperclip`, `keyboard`, `pywin32`

### Голосовой ввод (C:/Ren/tools/voice-to-text/)
- **Горячая клавиша:** `Ctrl+/` (slash)
  - Было `Ctrl+1`, но он переключал вкладки в браузере
  - Было `Ctrl+Q`, но пользователь попросил сменить
- **Режим:** toggle
  - Первое нажатие — начать запись
  - Второе нажатие — остановить запись и распознать
- **Поведение:** текст вставляется в поле ввода, **Enter нажимает пользователь сама**
- **Звуковая обратная связь:** писк при старте и остановке записи
- **Восстановление фокуса:** через `pywin32` окно чата возвращается в фокус перед вставкой

### Файлы проекта
- `main.py` — версия с окном (для теста и отладки)
- `main_background.py` — фоновая версия (без окна, логи в файл)
- `main_clipboard.py` — только копирует в буфер
- `test_hotkey.py` — тест хоткея
- `silent_start.vbs` — тихий запуск без окна
- `start_voice.bat` — запуск с минимальным окном
- `toggle_autostart.bat` — добавляет/убирает автозагрузку

### Кодировка батников
- Переписаны на **транслит** + `chcp 1251`
- UTF-8/emodzi вызывали кракозябры в cmd.exe

### Автозагрузка
- Настроена через `toggle_autostart.bat`
- Скрипт запускается с Windows, висит в фоне

## Команды

```powershell
# Запуск с окном (для теста)
cd C:\Ren\tools\voice-to-text
chcp 65001
py -3.12 main.py

# Автозагрузка (вкл/выкл)
.\toggle_autostart.bat
```
