# Политика конфиденциальности

**Дата вступления в силу:** 24 июня 2026 г.

## 1. Общие положения

Настоящая Политика конфиденциальности описывает, как приложение **«Планер»** (далее — «Приложение») собирает, использует и защищает информацию пользователей.

Приложение разработано для персонального планирования событий, задач и платежей. Мы уважаем вашу конфиденциальность и делаем всё возможное для защиты ваших данных.

## 2. Какие данные собираются

Приложение может собирать и обрабатывать следующие данные:

- **Данные аккаунта:** логин, номер телефона (используется только для восстановления доступа), хеш пароля.
- **Данные календартя:** события, задачи, встречи, платежи, которые вы создаёте.
- **Техническая информация:** тип устройства, версия ОС, информация о сетевом подключении (только для синхронизации).

Мы **не собираем**:
- Геолокацию без вашего явного согласия.
- Контакты из телефонной книги.
- Фотографии, камеру, микрофон.
- Данные о посещаемых сайтах.

## 3. Как используются данные

- **Аутентификация:** для входа в аккаунт и защиты ваших данных.
- **Синхронизация:** для передачи событий между вашими устройствами через выбранный вами сервер.
- **Уведомления:** для отправки локальных напоминаний о задачах и встречах.
- **Поддержка:** для помощи в восстановлении доступа к аккаунту.

## 4. Хранение и защита данных

- Ваши данные хранятся либо **локально на устройстве**, либо на **сервере, который вы сами выбираете** (self-hosted или облачный).
- Пароли хранятся в виде криптографических хешей (bcrypt).
- Передача данных между приложением и сервером осуществляется по протоколу HTTPS.
- Мы не передаём ваши данные третьим лицам для рекламных или коммерческих целей.

## 5. Локальные уведомления

Приложение может отправлять **локальные уведомления** на ваше устройство для напоминания о предстоящих событиях. Эти уведомления:
- Не требуют интернет-соединения.
- Не отправляются на внешние серверы.
- Могут быть отключены в настройках устройства.

## 6. Ваши права

Вы имеете право:
- Удалить свой аккаунт и все связанные данные.
- Отключить синхронизацию и работать полностью offline.
- Удалить приложение в любой момент — все локальные данные будут удалены с устройства.

## 7. Изменения политики

Мы можем обновлять настоящую Политику конфиденциальности. О всех существенных изменениях пользователи будут уведомлены через обновление приложения.

## 8. Контакты

По вопросам, связанным с обработкой персональных данных, вы можете связаться с нами через Issues репозитория на GitHub.
