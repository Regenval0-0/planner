## ✅ Выполнено

### 1. Извлечение данных из игры
- **Игра:** Do No Harm (Steam, Unity)
- **Путь к файлам:** `C:/Program Files (x86)/Steam/steamapps/common/Do No Harm/`
- **Инструменты:** `UnityPy` (Python), AssetStudio, AssetRipper

**Что извлечено:**
- `extracted/sprites/` — 136 спрайтов
- `extracted/textures/` — 49 текстур
- `extracted/images/` — прочие изображения
- `extracted/dnh_individual_sprites/` — отдельные спрайты
- `extracted/dnh_game_strings.txt` — полный дамп строк

**Ключевые механики:**
- 4 гумора: Blood, Phlegm, Yellow Bile, Black Bile
- Дозы не аддитивны
- Эффекты: +3 … -3
- Диапазоны: Baixa (1–5), Alta (6–9)
- Fishman: штраф ×½ без микса
- Аллергии блокируют гуморы
- Женщины уязвимы к высоким дозам чёрной желчи

### 2. Приложение-калькулятор — ГОТОВО ✅
**Формат:** Сайт (HTML + CSS + JS), открывается в браузере через сервер
**Локация:** `app/dist/` — готовые файлы

**Компоненты:**
- `PatientProfile` — выбор пациента (иконка, состояние, аллергия, блок гумора, внутренние симптомы)
- `SymptomGallery` — 19 реальных иконок симптомов из игры (внешние)
- `DoseCalculator` — тестовая доза + результат → perfect dose
- `MixCalculator` — подбор микса для Fishman

**Обновления UI:**
- Уникальные иконки для каждого пациента (тело, глаза, рот)
- Цветной бейдж начального состояния (Слабый, Критическое, Без сознания и т.д.)
- Внутренние симптомы — плашки (головокружение, тошнота, слабость и т.д.)
- Разделение симптомов на внешние (визуальные) и внутренние (словесные)

**Как запустить:**
1. Двойной клик `ЗАПУСТИТЬ.bat` → откроется браузер
2. Или открой `app/dist/ОТКРЫТЬ САЙТ.url`
3. Или `app/dist/ЗАПУСТИТЬ СЕРВЕР.bat`

**Фикс пустой страницы:**
- Причина: кэш Vite + старые type-импорты
- Решение: пересобрано с очисткой, исправлены `import type`
