# 📁 setup/

**Назначение:** Скрипты первоначальной настройки, VPN, инструментов.

---

## Содержимое

| Файл | Назначение |
|------|-----------|
| `enable-hiddify-auto.bat` | Автозапуск Hiddify VPN |
| `finish-setup.bat` | Финальная настройка системы |
| `install-warp.bat` | Установка Cloudflare WARP |
| `setup-autostart.bat` | Настройка автозапуска |
| `setup-psiphon.bat` | Установка Psiphon VPN |
| `setup-telegram-vpn.bat` | Настройка VPN через Telegram |
| `install-all-vibe-tools.bat` | Установка всех vibe-coding инструментов |

---

## ⚠️ Предупреждение

VPN-скрипты (`hiddify`, `warp`, `psiphon`) — для обхода блокировок.  
Используй только легальные VPN в твоём регионе.
